# Sanjana Sinha — Portfolio

A responsive, static portfolio built with HTML, CSS, and JavaScript. Visual direction: deep navy, restrained violet accents, clean typography, real project screenshots, and a recruiter-focused content hierarchy.

## Files
- `index.html` — portfolio content and sections
- `styles.css` — responsive visual system and layout
- `script.js` — mobile navigation and current year
- `assets/sanjana-sinha-resume.pdf` — résumé download
- `assets/lung-results.png` — Lung Cancer Prediction example result screenshot
- `assets/ems-dashboard.png` — Employee Management System admin dashboard screenshot

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub portfolio repository.
2. In repository Settings, open Pages.
3. Choose deploy from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.
